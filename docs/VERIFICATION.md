# Сверка с инструментами NASA

Вопрос: воспроизводит ли наш конвейер (загрузка, приведение сетки, маски, среднее по территории) то, что NASA
считает из тех же продуктов своими инструментами? Код: `backend/app/verify.py`, пакетная проверка:
`tools/verify_all.py`, на сайте: окно «Методика и доказательства», блок «Сверка с инструментами NASA».

## Инструменты

| Инструмент | Что делает | Для каких переменных |
|---|---|---|
| **NASA Giovanni** через Harmony (`giovanni-averaging-service`) | среднее по прямоугольнику, которое NASA считает из исходных файлов на родном разрешении | GPM IMERG, GLDAS (влага почвы, корневой слой, испарение, сток, снег), AIRS (температура, водяной пар, уходящее излучение) |
| **NASA POWER API** (месячные значения в точке) | то же облако NASA POWER, но через его официальный API | все переменные из NASA POWER: MERRA-2, IMERG, CERES / MODIS |

Giovanni рекомендован в ресурсах челленджа. Его сервис усреднения принимает только внутренние идентификаторы
полей Giovanni (`GPM_3IMERGM_07_precipitation`, `GLDAS_NOAH025_M_2_1_SoilMoi0_10cm_inst`,
`AIRS3STM_7_0_SurfAirTemp_A`), а не имена переменных из каталога: с обычными именами Harmony отвечает
«Bad or missing variable input». Задание выполняется за 15-40 секунд на 25 лет.

## Что сравнивается

Оба месячных ряда за общий период: корреляция значений и аномалий (без сезона), средняя разница в процентах,
RMSE и тренд обоих рядов той же статистикой, что в инструменте. Вывод: «совпадает» (корреляция аномалий не
ниже 0,95 и разница не больше 5%), «согласуется» (корреляция аномалий не ниже 0,8), «расходится». Для
переменных AIRS сравнивается среднее восходящих и нисходящих витков, как в нашем кубе. Результаты кэшируются.

## Что нашла сверка

- **Единицы солнечного света в POWER API.** Первая проверка `sw_down` в Дели дала корреляцию 1,000 при разнице
  в 11,57 раза: API отдаёт суточную энергию в МДж/м² (1 МДж/м²/сут = 11,574 Вт/м²), а облачное хранилище POWER, из
  которого загружен наш куб, хранит средний поток в Вт/м². Наши данные верны; инструмент сверки теперь читает
  единицы из ответа API и пересчитывает их (`POWER_UNIT_FACTOR`).
- **Осадки IMERG.** Мы берём их из облака NASA POWER (сетка 0,1°, затем 0,5°), Giovanni считает по исходным файлам
  GES DISC на 0,1°: разница средних меньше 1%, тренды совпадают до третьего знака. Путь через POWER не искажает данные.

## Ограничения

- Giovanni работает с прямоугольниками: территория проверяется по охватывающему прямоугольнику, а не по
  границе страны; территории через линию перемены дат не проверяются.
- Для MODIS (NDVI, температура поверхности), OMI и хлорофилла прямого инструмента сверки в Harmony нет
  (их коллекции не подключены к сервису усреднения Giovanni).
- Сверка проверяет наш конвейер, а не сами данные NASA: если в продукте NASA есть ошибка, совпадут обе стороны.
